# BotC 그리모어 — PRD (Product Requirements Document)

> 시계탑에 흐른 피(Blood on the Clocktower) 게임을 원활히 플레이하기 위한 웹 보조 도구
> 작성일: 2026-06-07 · 상태: Draft v0.1

---

## 1. 개요 (Overview)

**제품명(가칭):** BotC 그리모어

**한 줄 설명:** 시계탑에 흐른 피(이하 "시계피") 오프라인 모임에서, 직업·시트·규칙을 빠르게 참조하고, 향후 스토리텔러가 노트북에서 로컬 서버를 띄워 같은 WiFi의 플레이어 폰으로 역할 토큰을 공유하는 보조 도구.

**배경/문제:**
- 시계피는 직업이 매우 많고(에디션별 수십 종), 능력·야간 순서·징크스 등 참조할 정보가 많다.
- 오프라인 모임에서 스토리텔러가 종이 그리모어/물리 토큰을 쓰면 준비·진행이 번거롭다.
- 기존 참고 사이트([botc.vnamu.com](https://botc.vnamu.com))는 직업/시트/규칙 레퍼런스는 훌륭하나, 우리 모임 운영 방식(노트북 로컬 서버 + 폰 토큰 공유)에 맞는 그리모어 기능이 없다.

**제품 비전:** 직업/시트/규칙 레퍼런스(Phase 1) + 로컬 네트워크 기반 디지털 그리모어(Phase 2)를 한 사이트에서 제공.

---

## 2. 목표와 비목표 (Goals / Non-Goals)

### Phase 1 목표 (이번 PRD 핵심)
- 전체 직업 목록 페이지(`/`)와 직업 상세 페이지 제공
- 공식 시트 3종(트러블 브루잉 / 배드 문 라이징 / 종파의 제비꽃) 목록 및 상세 제공
- 시계피 기본 규칙 페이지(`/rules`) 제공
- 모든 콘텐츠 한국어 + 영어 병기
- 데이터는 정확하고 구조화 (향후 그리모어가 동일 데이터를 재사용)

### Phase 2 목표 (그리모어 — 별도 기획 후 추가)
- 노트북에서 로컬 서버 구동, 같은 WiFi 내 폰이 접속
- 단일 게임 세션 상태를 다수 기기가 공유
- 스토리텔러가 역할을 배정하면 각 플레이어 폰에 자기 역할 토큰이 실시간 표시
- 스토리텔러용 그리모어 전체 뷰(좌석/역할/리마인더/상태 관리)

### 비목표 (Non-Goals)
- 인터넷 공개 배포 / 다중 룸 SaaS / 매치메이킹
- 회원가입·계정 시스템 (로컬 개인용)
- 자동 진행(봇 스토리텔러), 음성/영상 기능
- 모바일 네이티브 앱 (반응형 웹으로 충분)

## 3. 사용자 (Personas)

| 페르소나 | 기기 | 주 사용 | Phase |
|---|---|---|---|
| **스토리텔러** | 노트북 | 그리모어 전체 뷰, 역할 배정·관리, 규칙/시트 참조 | 1·2 |
| **플레이어** | 폰 | 자기 역할 토큰 확인, 시트/규칙 열람 | 1·2 |
| **열람자(준비 중)** | 데스크탑/폰 | 직업·시트·규칙 학습/예습 | 1 |

Phase 1에서는 세 페르소나 모두 "레퍼런스 열람자"로 동작하며, Phase 2에서 스토리텔러/플레이어 역할이 분화된다.

## 4. 범위와 단계 (Scope & Phases)

```
Phase 1 — 콘텐츠 레퍼런스 (이번 PRD)
  ├─ 직업 목록(/) + 직업 상세
  ├─ 시트 목록(/sheets) + 시트 상세
  └─ 규칙(/rules)

Phase 2 — 디지털 그리모어 (별도 PRD)
  ├─ 로컬 서버 + LAN 접속
  ├─ 세션 공유 + 실시간 동기화
  ├─ 스토리텔러 뷰 / 플레이어 뷰
  └─ 역할 배정 · 좌석 · 리마인더 관리
```

> Phase 2는 사용자가 별도 기획한다. 단, **Phase 1의 기술 기반은 Phase 2를 지원할 수 있게 설계**한다(§8 참조).

## 5. 기능 요구사항 — Phase 1 (Functional Requirements)

### 5.1 직업 목록 페이지 (`/`)
- 직업 분류 6종으로 그룹핑: **마을주민(Townsfolk) / 외부인(Outsider) / 하수인(Minion) / 악마(Demon) / 여행자(Traveller) / 전설(Fabled)**
- 각 직업 카드: 아이콘, 이름(한/영), 소속 에디션, 능력 요약
- 필터/검색:
  - 에디션별 필터 (트러블 브루잉 / 배드 문 라이징 / 종파의 제비꽃 / 기타)
  - 분류별 필터
  - 이름·능력 텍스트 검색
- 카드 클릭 → 직업 상세 페이지 이동

### 5.2 직업 상세 페이지 (`/characters/[id]`)
표시 항목:
- 이름(한/영), 아이콘, 분류, 소속 에디션
- 능력 전문(한/영)
- 야간 순서: 첫날밤 순서 / 그 외 밤 순서 (해당 없으면 표기)
- 리마인더 토큰 목록
- 셋업 효과 여부 및 내용 (예: 남작 → 외부인 +2)
- 징크스(jinx): 특정 직업과 함께 있을 때의 상호작용 규칙
- (있다면) 운영 팁/가이드

### 5.3 시트 목록 페이지 (`/sheets`)
- 공식 시트 3종 우선 노출:
  - **트러블 브루잉 (Trouble Brewing)**
  - **배드 문 라이징 (Bad Moon Rising)**
  - **종파의 제비꽃 (Sects & Violets)**
- 각 시트 카드: 이름(한/영), 구성 직업 수, 난이도/설명(있으면)
- (커스텀 시트 생성/공유는 Phase 1 범위 제외 — §13 오픈 이슈)

### 5.4 시트 상세 페이지 (`/sheets/[id]`)
- 해당 시트에 포함된 전체 직업을 분류별로 표시 (목록 페이지와 동일 카드 재사용)
- 각 직업 능력 요약 + 상세 링크
- 야간 순서표 (첫날밤 / 그 외 밤) — 시트 단위로 정렬된 순서
- 인쇄/큰 화면 표시에 적합한 레이아웃

### 5.5 규칙 페이지 (`/rules`)
- 시계피 기본 규칙 전문
- 섹션 예시: 게임 개요 / 구성과 준비 / 낮·밤 진행 / 지명과 처형 / 승리 조건 / 직업 분류 설명 / 스토리텔러의 역할
- 목차(앵커 네비게이션)로 섹션 점프

## 6. 데이터 모델 (Data Model)

콘텐츠는 정적 JSON으로 관리하고, Phase 2 그리모어가 **동일한 데이터 소스를 재사용**한다.

### Character
```jsonc
{
  "id": "washerwoman",
  "name": { "ko": "세탁부", "en": "Washerwoman" },
  "edition": "trouble-brewing",       // trouble-brewing | bad-moon-rising | sects-and-violets | other
  "team": "townsfolk",                // townsfolk | outsider | minion | demon | traveller | fabled
  "ability": { "ko": "...", "en": "..." },
  "firstNight":  { "order": 33, "reminder": { "ko": "...", "en": "..." } },  // null 가능
  "otherNight":  { "order": null, "reminder": null },
  "reminders": ["Townsfolk", "Wrong"],
  "setup": false,                      // 셋업에 영향 주는 직업이면 true
  "setupNote": { "ko": "", "en": "" },
  "jinxes": [ { "with": "baron", "reason": { "ko": "...", "en": "..." } } ],
  "image": "/icons/washerwoman.png"
}
```

### Sheet (Edition / Script)
```jsonc
{
  "id": "trouble-brewing",
  "name": { "ko": "트러블 브루잉", "en": "Trouble Brewing" },
  "description": { "ko": "...", "en": "..." },
  "difficulty": "beginner",
  "characterIds": ["washerwoman", "librarian", "..."]
}
```

### RulesSection (규칙)
```jsonc
{ "id": "win-conditions", "title": { "ko": "승리 조건", "en": "..." }, "body": { "ko": "...(markdown)", "en": "..." }, "order": 5 }
```

> 야간 순서는 직업의 `firstNight.order` / `otherNight.order`로 전역 정렬하며, 시트 상세에서는 해당 시트 직업만 필터링해 표시한다.

## 7. 데이터 수집 계획 (Data Acquisition)

**출처:** [botc.vnamu.com](https://botc.vnamu.com) (한글 데이터 보유)

**방식:** 해당 사이트가 직접 HTTP fetch에 403을 반환하고 SPA(JS 렌더)이므로, **브라우저 자동화 도구로 렌더링 후 추출**한다.
1. 직업 목록 페이지에서 전체 직업 ID/링크 수집
2. 각 직업 상세 페이지에서 능력·야간 순서·리마인더·셋업·징크스 추출
3. 시트 3종 상세에서 구성 직업 매핑
4. 규칙 페이지 섹션 텍스트 추출
5. 직업 아이콘 이미지 다운로드 → 로컬(`/public/icons`) 호스팅
6. 영어 원문 매핑(공식 영문 명칭/능력) 병기

**산출물:** `data/characters.json`, `data/sheets.json`, `data/rules.json` + 아이콘 에셋

**유의(저작권):** 시계피 IP는 The Pandemonium Institute 소유. 본 도구는 **비상업·개인/로컬 모임용 팬 콘텐츠**로 한정하고, 데이터 출처를 표기한다. 공개 배포 시 별도 검토 필요.

## 8. 향후 그리모어 아키텍처 제약 (Phase 2 Forward-Compatibility)

Phase 1 구현이 Phase 2를 막지 않도록, 처음부터 다음을 전제로 셋업한다.

- **로컬 서버 구동형:** 정적 export가 아니라 Node 서버로 실행 (`next build && next start`). → LAN에서 API/실시간 통신 가능.
- **LAN 노출:** 서버를 `0.0.0.0`에 바인딩. 같은 WiFi의 폰이 `http://<노트북IP>:<포트>`로 접속.
- **단일 세션 공유:** 하나의 게임 세션 상태를 서버(메모리 또는 SQLite/파일)에서 보관, 다수 기기가 동일 세션 구독.
- **실시간 푸시:** 스토리텔러가 역할 배정 시 플레이어 폰에 즉시 반영 → WebSocket(Socket.io 등) 또는 SSE.
- **뷰 분리:** 스토리텔러 뷰(노트북, 전체 그리모어) vs 플레이어 뷰(폰, 자기 토큰만).

> 결론: Phase 1은 콘텐츠 사이트지만 **배포 형태를 "로컬 Node 서버"로 고정**하고, 데이터/컴포넌트를 그리모어가 재사용할 수 있게 모듈화한다.

## 9. 비기능 요구사항 (Non-Functional)

- **반응형:** 폰(플레이어 뷰 핵심) / 태블릿 / 노트북 모두 대응
- **로컬/오프라인 동작:** 인터넷 없이 LAN만으로 동작 (데이터·이미지·폰트 로컬 번들)
- **성능:** 콘텐츠 페이지는 사전 렌더(SSG/캐시), 직업 검색·필터는 클라이언트 즉시 반응
- **가독성/테마:** 어두운 테마 기본(밤 진행 분위기), 토큰/아이콘 대비 확보
- **다국어:** ko/en 병기 (토글 또는 동시 표기 — §13)

## 부록 A. 시계피 도메인 메모

- 공식 베이스 에디션 3종: 트러블 브루잉(입문), 배드 문 라이징(중급), 종파의 제비꽃(중급)
